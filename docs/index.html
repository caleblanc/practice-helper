What it does

Everything a drumming session needs, automated.

Songsterr → MIDI & Guitar Pro
Search any song, select a revision, and download the full arrangement as a standard MIDI file or a Guitar Pro 5 file — with every instrument on its own track.
17 tracks · 114 BPM · triplet feel
Apple Music → Stems
Download any Apple Music track and split it with Demucs into a drums-only (OD) and no-drums (ND) WAV — ready to load into your DAW at full resolution.
htdemucs · MPS / CUDA / CPU
Accurate rhythmic feel
Detects triplet-eighth vs. straight-sixteenth feel per track using note positions and inter-note gaps, so the GP5 displays in correct notation — not a grid of 16th rests.
Position + gap analysis
Notation control
Choose whether Guitar Pro files open in Standard notation, TAB only, or both — with a toggle in Settings that persists across sessions.
Standard · TAB · Both
Organised output
Every download lands in its own Artist - Title/ subfolder. MIDI, GP5, OD stem, and ND stem always travel together.
Zero manual filing
Mac & Windows
Runs natively on macOS (afconvert + MPS) and Windows (ffmpeg + CUDA or CPU). One codebase, both platforms.
customtkinter UI

Workflow

Search once. Get everything.

1
Search for a song
Type any artist or song. Apple Music and Songsterr results appear side-by-side. Select one or both.
2
Pick your outputs
Check Drums Only stem, No-Drums stem, MIDI, and/or Guitar Pro. Choose which Songsterr tracks go in the MIDI.
3
Hit Process
Downloads run in parallel. Files land in a named folder in your stems directory — ready for Guitar Pro and your DAW.

Installation

Up in five minutes.

macOS / Windows
# Clone and set up
$ git clone https://github.com/caleblanc/practice-helper
$ cd practice-helper
$ python -m venv .venv
 
# macOS
$ source .venv/bin/activate
# Windows
> .venv\Scripts\activate
 
$ pip install -r requirements.txt
$ python app.py
✓ Practice Helper
Windows — double-click launcher
# Or just run launch.bat
> launch.bat
Apple Music
Requires an Apple Music subscription and a cookies.txt file exported from your browser. Set the path in Settings on first launch.
Guitar Pro files
.gp5 files open in Guitar Pro 5–8. The converter handles multi-track arrangements, feel detection, and correct notation automatically.
Windows: ffmpeg required
Stem extraction needs ffmpeg on your PATH. Download from ffmpeg.org and add the bin/ folder to your system PATH.
Output folder
Defaults to ~/Music/Practice Helper/Songs/ — change it in Settings to any folder you like.
